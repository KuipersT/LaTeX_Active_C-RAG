\section{Problem Formulation}

\input{figures/system.tex}

In the state-of-the-art reviewed in Section~\ref{sec:background}, the evidence used to guage factuality of the subclaims is retrieved in a single phase before the subclaims are generated. Therefore, a true subclaim whose evidence was not retrieved has no way of being validated, and will be removed from the final set \eqref{eq:filter_set}. In this work, we seek to alleviate this issue by allowing the system to consider its current subclaims, and either stop and answer, or retrieve further evidence for the subclaims that it cannot yet support and revise them. This effectively integrates active RAG \tk{refs} wth conformal factuality \tk{refs} with the aim of producing larger, and thus more informative, certified filtered sets \eqref{eq:filter_set}. Accordingly, we refer to our approach as Active C-RAG (AC-RAG).

As illustrated in Figure~\ref{fig:system}, AC-RAG system answers a query $x$ over rounds $t = 0, 1, \ldots, T$, for a budget $T$ that is fixed in advance, and at round $t$ it holds the subclaims $\hat{y}_t$ and the evidence $D_t$. Round $0$, shown in black, is connected (?) to CF \tk{ref} and C-RAG \tk{ref}, as described in Section~\ref{sec:background}, whereas the rounds $t \geq 1$, shown in blue, are only affected by AC-RAG when reworking its subclaims.

The system has access to a retriever over a fixed corpus $\mathcal{K}$, and we write $\mathrm{Retrieve}(q)$ for the set of documents that it returns for a retrieval query $q$. Round $0$ starts with the initial retrieval, which maps the query $x$ to the evidence $D_0$. As in multi-hop C-RAG, the initial retrieval may run over several hops. We denote with $D_0$ the union of the documents retrieved over all hops.

An LLM $G$ then writes the claim $y = G(x, D_0)$ from the query and the initial retrieved evidence. Subclaim extraction is performed by another LLM that splits $y$ into the subclaims $\hat{y}_0$, as in CF and C-RAG. The evidence $D_0$ is also placed into an evidence store, which holds the evidence $D_t \subseteq \mathcal{K}$ collected up to round $t$.

At each round $t$, a subclaim scorer assigns a score $s_t(c \mid x, D_t)$ to every subclaim $c \in \hat{y}_t$ based on the query and the current retrieved evidence $D_t$, and we write $s_t = \{ s(c \mid x, D_t) : c \in \hat{y}_t \}$ for the scores of all subclaims of set $\hat{y}_t$.

The scores $s_t$ are used by a decision block to partition the set $\hat{y}_t$ into three subsets
\begin{equation}
  (k_t, w_t, z_t) = \mathrm{Dec}(s_t)
\end{equation}
where subset $k_t$ contains the subclaims that are kept, $w_t$ the subclaims that are to be reworked, and $z_t$ the subclaims that are removed. It also decides whether to stop at the current round $t$, returning the current non-rejected subclaims
\begin{equation}
  \hat{y}_{t^*} = k_{t^*} \cup w_{t^*}
\end{equation}
where $t^{*}$ is the stopping time, to the fnal filtering step, together with $D_{t^*}$ and $s_{t^*}$, to the final selection.

Whilst the system has not stopped, it reworks the subclaims in subset $w_t$ in the rounds shown in blue in Figure~\ref{fig:system}. To this end, for each subclaim $c \in w_t$, a retrieval query $qt = q_t(c)(x, c, D_t)$ is produced as function of the input query, the subclaim and the evidence, and the documents returned for these queries are added to the evidence store as
\begin{equation}
  D_{t+1} = D_t \cup \bigcup_{c \in w_t} \mathrm{Retrieve}\bigl(q_t\bigr).
  \label{eq:store}
\end{equation}
The subclaim revision block then outputs the modifed subclaims for the next round
% \begin{equation}
%   \hat{y}_{t+1} = \mathrm{Rev}(x, k_t, w_t, D_{t+1}) 
% \end{equation}
\begin{equation}
  \hat{y}_{t+1} = k_t \cup \mathrm{Rev}(x, w_t, D_{t+1}) 
\end{equation}
in which each subclaim of $w_t$ is rewritten given the new evidence.
% \tk{or left unchanged -- plausible that no rewriting is necessary if we retrieve the correct evidence (i.e. Steven Spielberg's biography)}. 
New subclaims may also be added. The next round  begins from the subclaim scoring of the updated subclaims $\hat{y}_{t+1}$.

Finally, the returned filtered set is given by $\hat{y} = F_{\hat{\tau}}(\hat{y}_{t^*})$, where the threshold $\hat{\tau}$ is calibrated using calibration data as in CF and C-RAG via \eqref{eq:filter_set}. 

The answer that the system finally returns must still satisfy the guarantee \eqref{eq:cf}, that is,
\begin{equation}
  \Pr\bigl[\, y^* \Rightarrow c \ \text{for every} \ c \in \hat{y} \,\bigr] \geq 1 - \alpha,
  \label{eq:cf_seq}
\end{equation}
where the probability is now also taken over the choices that the system makes in each round. Since abstaining always satisfies the guarantee, we measure how useful the system is by the expected number of supported subclaims in its answer,
\begin{equation}
  U = \mathbb{E}\Bigl[ \sum_{c \in \hat{y}} a(c) \Bigr],
  \label{eq:usefulness}
\end{equation}
and the goal is to ensure that $U$ as large as possible while keeping the guarantee \eqref{eq:cf_seq}.
